# Winter Arc 2026

Plan de 92 días (1 de octubre al 31 de diciembre de 2026) para seguir cinco hábitos diarios: entrenar, comer, dormir, leer y crecer.

Es una app web instalable. Ábrela en el celular desde GitHub Pages y usa "Agregar a la pantalla principal" o "Instalar aplicación". Funciona sin internet y guarda los datos en el propio teléfono.
